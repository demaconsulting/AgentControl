# Introduction

This document contains the review plan for the Agent Control project.

## Purpose

This review plan defines the review-sets and the evidence required to demonstrate
that each software item has been reviewed according to the project's compliance
requirements.

## Scope

This document covers all review-sets defined in `.reviewmark.yaml` for Agent Control.

## Generation Source

This plan is automatically generated by the ReviewMark tool, listing every configured
review-set together with its current coverage status against the reviewed files.

## Audience

This document is intended for:

- Software developers working on Agent Control
- Quality assurance teams planning review activities
- Project stakeholders reviewing compliance status
- Auditors verifying that review coverage is complete
